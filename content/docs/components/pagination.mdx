### Usage
```tsx
import { Pagination } from "sabalong-ui";

const [page, setPage] = useState(1);

<Pagination page={page} totalPages={12} onChange={setPage} />
```

`page` and `onChange` are required (controlled). The prev/next buttons are automatically disabled at the edges, and distant page numbers are shortened to ellipsis.
