### Usage
```tsx
import { Notification } from "sabalong-ui";

<Notification
  variant="success"
  title="Saved successfully!"
  message="Your changes have been saved."
  duration={5000}
  onClose={() => {}}
/>
```

The progress bar shrinks from `100%` to `0%` over `duration` ms (default `5000`), then `onClose` is fired automatically.
