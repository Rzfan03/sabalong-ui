### Usage

```tsx
const plans = [
  { label: "Starter — Free", value: "starter" },
  { label: "Pro — $12/month", value: "pro" },
];

<RadioGroup label="Choose a plan" options={plans} onChange={(value) => console.log(value)} />
```

### Usage
```tsx
import { RadioGroup } from "sabalong-ui";

const themes = [
  { label: "Light", value: "light" },
  { label: "Dark", value: "dark" },
];

<RadioGroup label="Theme settings" options={themes} direction="horizontal" />
```

Set `direction="horizontal"` to arrange options in a row. Options with `disabled: true` are automatically disabled.
