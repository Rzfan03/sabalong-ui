### Usage
```tsx
import { Breadcrumb } from "sabalong-ui";

<Breadcrumb
  items={[
    { label: "Home", href: "/" },
    { label: "Docs", href: "/docs" },
    { label: "Breadcrumb" },
  ]}
/>
```

The last item renders as the active page (no link). Other items with an `href` become links.
