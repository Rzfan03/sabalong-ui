### Usage
```tsx
import { Stat } from "sabalong-ui";
import { IoPeople } from "react-icons/io5";

<Stat
  label="Total Users"
  value="12.430"
  trend="up"
  trendLabel="+12.5%"
  icon={<IoPeople />}
/>
```

`trend="up"` shows a green arrow, `trend="down"` a red arrow. `icon` is optional and renders in the badge on the right.
