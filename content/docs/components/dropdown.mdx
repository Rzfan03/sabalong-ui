### Usage
```tsx
import { Dropdown } from "sabalong-ui";

<Dropdown
  label="Actions"
  items={[
    { label: "Edit", onClick: () => {} },
    { label: "Delete", danger: true },
  ]}
/>
```

Pass a custom `trigger` node to replace the default button. Closes on outside click.
