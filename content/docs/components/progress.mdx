### Usage
```tsx

<Progress value={value} showLabel onChange={setValue} />
```

### Indeterminate

<ProgressIndeterminate />
</div>

### Usage
```tsx

<Progress indeterminate />
```

Set `indeterminate` for a loading mode without a definite value. The `value` is automatically clamped to 0–100.
