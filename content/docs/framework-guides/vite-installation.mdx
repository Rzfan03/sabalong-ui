description: How to install and setup SabalongUI in Vite
---

### Setup Vite

> **Tip:** prefer a ready-to-run project? Run `npm create sabalong-ui@latest` and pick **Vite** — no manual steps needed.

```bash
npm create vite@latest my-app -- --template react-ts
```

### Install Tailwindcss
```bash
npm install tailwindcss @tailwindcss/vite
````

### Configure Vite Config
```bash
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
  ],
})
```

### Import tailwindcss
```css
@import "tailwindcss";
@source "../node_modules/sabalong-ui/dist/**/*.{js,cjs,mjs}";
```

### Setup SabalongUI
```bash
npm install sabalong-ui
```
Done! now you use Vite and SabalongUI
