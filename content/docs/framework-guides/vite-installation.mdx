---
title: Vite
description: How to install and setup SabalongUI in Vite
---

### Setup Vite

```bash
npm create vite@latest my-app -- --template react-ts
```

### Install Tailwindcss
```bash
npm install tailwindcss @tailwindcss/vite
````

### Configure Vite Config
```bash
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
  ],
})
```

### Import tailwindcss
```bash
@import "tailwindcss";
```

### Setup SabalongUI
```bash
npm install sabalong-ui
```
Done! now you use Vite and SabalongUI
