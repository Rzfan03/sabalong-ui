title: NextJS
description: How to install and setup SabalongUI in NextJS
---

### Setup NextJS

> **Tip:** prefer a ready-to-run project? Run `npm create sabalong-ui@latest` and pick **Next.js** — no manual steps needed.

```bash
npx create-next-app@latest
```

### Install Tailwindcss
```bash
npm install tailwindcss @tailwindcss/postcss postcss
````

### Configure PostCss
```bash
const config = {
  plugins: {
    "@tailwindcss/postcss": {},
  },
};

export default config;
```

### Import tailwindcss
```css
@import "tailwindcss";
@source "../../node_modules/sabalong-ui/dist/**/*.{js,cjs,mjs}";
```

### Setup SabalongUI
```bash
npm install sabalong-ui
```
Done! now you use NextJS and SabalongUI
