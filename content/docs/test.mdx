## Quick Start

### Scaffold a New Project (Recommended)

The fastest way to get started — creates a fresh project with **Vite + React (TypeScript)** or **Next.js (App Router)**, with Tailwind CSS v4 preconfigured and wired to the library:

```bash
npm create sabalong-ui@latest
```

Pick a framework when prompted. For a non-interactive setup (scripts/CI):

```bash
npm create sabalong-ui@latest my-app -- --template template-vite
npm create sabalong-ui@latest my-app -- --template template-next
```

The generated project runs right away with `npm run dev` — the `@source` pointing at `sabalong-ui`'s `dist/` is already included, so all component styles are generated automatically.

Select your preferred framework to get started with SabalongUI. These guides assume you already have a project with Tailwind CSS installed.
